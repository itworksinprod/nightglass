# Nightglass v0.1.0

Nightglass is a privacy-first, local-only dynamic dark reader packaged for
personal use. This release contains no account system, analytics, advertising,
telemetry, remote configuration, or remotely executed code.

## Included downloads

- `nightglass-0.1.0-chromium.zip` — unpacked Manifest V3 resources for Chrome
  and Edge.
- `nightglass-0.1.0-firefox.xpi` — unsigned Firefox package for temporary or
  developer installation.
- `nightglass-0.1.0-safari-web-extension.zip` — Safari Web Extension resources
  ready for Apple's conversion and signing tools.
- `nightglass-0.1.0.user.js` — self-contained userscript for the Userscripts
  app on iPhone Safari.
- `INSTALL.md` — platform-specific installation instructions.
- `SHA256SUMS` — SHA-256 checksums for every downloadable artifact.

## Security and privacy highlights

- Local-only settings and per-host rules; no browser-sync storage.
- Strict extension-page Content Security Policy and no remote executable code.
- SHA-256-pinned, locally bundled Dark Reader renderer with documented patches.
- Native page-context CORS resource retrieval without credentials or redirects.
- Bounded request count, response size, concurrency, queue, time, and total bytes.
- Versioned settings validation, memory-only renderer caches, and deterministic
  release packaging.

Nightglass integrates the pinned MIT-licensed Dark Reader rendering engine.
Nightglass owns the activation rules, native-dark detection, privacy boundary,
presets, settings, platform adapters, interface, packaging, and verification.

## Verified status and limitations

The release pipeline rebuilds the project, enforces repository policy, runs the
complete automated suite, packages every target, and verifies the published
checksums before creating the release.

Packaged-extension smoke tests have passed in Chrome, Firefox, and Safari.
Installation on a physical iPhone remains unverified. Browser-internal pages,
built-in PDF viewers, inaccessible cross-origin frames, closed shadow roots,
and canvas pixels cannot always be recolored.
