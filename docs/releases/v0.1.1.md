# Nightglass v0.1.1

Nightglass v0.1.1 is a visual-consistency patch for the privacy-first,
local-only dark reader. It retains the same privacy boundary: no account,
analytics, advertising, telemetry, remote configuration, or remote code.

## What changed

- The popup, settings, rendering lab, and documentation now use the same
  official moon-in-a-cyan-magnifying-glass icon.
- All product surfaces share one navy, teal, cyan, and ice palette derived from
  the packaged icon.
- The default Neutral theme now uses the matching navy background and ice text.
- The rendering fixture is correctly labeled **Nightglass Rendering Lab**.
- Repeatable, local-only preview fixtures and automated identity tests prevent
  screenshots and shipped UI from drifting apart again.

## Included downloads

- `nightglass-0.1.1-chromium.zip` — unpacked Manifest V3 resources for Chrome
  and Edge.
- `nightglass-0.1.1-firefox.xpi` — unsigned Firefox package for temporary or
  developer installation.
- `nightglass-0.1.1-safari-web-extension.zip` — Safari Web Extension resources
  ready for Apple's conversion and signing tools.
- `nightglass-0.1.1.user.js` — self-contained userscript for the Userscripts
  app on iPhone Safari.
- `INSTALL.md` — platform-specific installation instructions.
- `SHA256SUMS` — SHA-256 checksums for every downloadable artifact.

The release pipeline rebuilds all targets, enforces the local-only policy,
runs the full test suite, packages each browser target, and verifies checksums
before publishing.
